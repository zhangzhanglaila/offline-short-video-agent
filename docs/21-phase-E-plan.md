# Phase E 系列开发规划

## 总体目标

在现有 Agent 系统（Phase 0-5）和动态化增强（D1-D6）基础上，添加模板系统、AI 生图/生视频能力、历史管理 UI，使系统成为完整的短视频生成平台。

**核心原则**:
- 保守节奏，每月一个大功能
- 每阶段完成后展示效果
- 保证质量，稳定优先
- 现有功能完全兼容

---

## 阶段概览

| 阶段 | 名称 | 预计周期 | 核心目标 | 输出 |
|------|------|---------|---------|------|
| **E0** | 基础设施准备 | 3-5 天 | 目录规范、文档体系、开发日志 | `templates/`、`docs/20-27.md` |
| **E1** | 模板系统 | 4 周 | 迁移全部 HTML 模板 + 渲染引擎 | 25+ 可用模板 |
| **E2** | AI 生图集成 | 4 周 | OpenAI/DashScope API 直连 | 图片生成服务 |
| **E3** | AI 生视频集成 | 4 周 | 通义 WAN/可灵 API | 视频生成服务 |
| **E4** | 历史管理 UI | 2 周 | 完整历史记录 + 前端页面 | 历史管理页面 |
| **E5** | ComfyUI 集成 | 4 周 | 本地 ComfyUI 支持 | 无成本 AI 生成 |

---

## E0: 基础设施准备（3-5 天）

### 目标
建立规范的目录结构和文档体系。

### 主要任务
1. 创建 `templates/` 目录（按分辨率分类）
2. 创建 `workflows/` 目录（TTS/图像/视频配置）
3. 创建 `services/` 目录（新增服务层）
4. 完善文档体系（`docs/20-27.md`）
5. 规范开发日志（`devlog/daily/`）
6. 更新 `CLAUDE.md`

### 详细规划
见 [`docs/22-E0-tasks.md`](22-E0-tasks.md)
