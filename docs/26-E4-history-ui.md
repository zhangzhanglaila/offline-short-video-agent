**API 设计**:
```python
# 获取历史记录
GET /api/history?page=1&limit=20&status=success
→ {
    "total": 100,
    "items": [
        {
            "id": "xxx",
            "input": "讲解Redis",
            "params": {...},
            "output": "path/to/video.mp4",
            "status": "success",
            "created_at": "2026-07-24T10:00:00"
        }
    ]
}

# 删除记录
DELETE /api/history/{id}
→ { "success": true }

# 重新生成
POST /api/history/{id}/regenerate
→ { "task_id": "xxx" }

# 导出记录
GET /api/history/export?format=csv
→ [CSV file]
```
