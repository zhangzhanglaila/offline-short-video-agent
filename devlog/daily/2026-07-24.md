- ✅ 真实测试通过：生成图片 1411.9 KB，耗时 9.63s

### WanX API 格式
```python
# Endpoint
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation

# 请求体
{
    "model": "wan2.6-t2i",
    "input": {
        "messages": [{"role": "user", "content": [{"text": "提示词"}]}]
    },
    "parameters": {
        "size": "1024*1024",
        "n": 1,
        "watermark": false,
        "prompt_extend": true
    }
}
```

### 图片缓存位置
`output/ai_cache/{provider}_{size}_{prompt_hash}.png`
